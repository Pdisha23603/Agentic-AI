TROUBLESHOOTING:
────────────────

Problem: "python3: command not found"
Solution: 
  • Install Python from https://www.python.org/
  • Use 'python' instead of 'python3' on Windows
  • Verify: python --version

Problem: "pip: command not found"
Solution:
  • Python 3 includes pip by default
  • Try: python3 -m pip install -r requirements.txt
  • Or reinstall Python with pip option enabled

Problem: "ModuleNotFoundError"
Solution:
  • Run: pip install -r requirements.txt
  • Verify file exists: ls requirements.txt
  • Check Python version: python3 --version

Problem: Permission denied
Solution (Mac/Linux):
  • Try: pip3 install --user -r requirements.txt
  • Or use: python3 -m pip install -r requirements.txt
