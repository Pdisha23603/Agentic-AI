# Session 15 – Task 5: AI Code Generation & Evolution Documentation

## 1. Task Objective
Use ChatGPT or Copilot to generate a LangChain code snippet that fetches and summarizes trending topics from a mock Twitter API, then test and modify the code to print the top 2 trends in your console.

---

## 2. The Original Code Snippet from ChatGPT / Copilot

Below is the raw, unedited code generated by asking ChatGPT / Copilot:
> *"Write a Python script using LangChain to fetch and summarize trending topics from a mock Twitter API."*

```python
# ==========================================
# RAW AI-GENERATED CODE (ChatGPT / Copilot)
# ==========================================
from langchain.llms import OpenAI
from langchain.chains import LLMChain
from langchain.prompts import PromptTemplate
import requests

def get_twitter_trends():
    # Mock Twitter API endpoint
    response = requests.get("https://api.mock-twitter.com/v2/trends")
    return response.json()

prompt = PromptTemplate(
    input_variables=["topic", "tweets"],
    template="Summarize the following Twitter trending topic {topic} based on these tweets:\n{tweets}"
)

llm = OpenAI(temperature=0.7)
chain = LLMChain(llm=llm, prompt=prompt)

trends = get_twitter_trends()

for trend in trends:
    summary = chain.run(topic=trend['name'], tweets=trend['sample_tweets'])
    print(f"Trend: {trend['name']}")
    print(f"Summary: {summary}")
```

## 3. Critical Issues & Why the Raw AI Code Failed

When testing the AI-generated code against modern LangChain (`langchain>=0.3 / 1.0`), the following critical issues occurred:

### Issue 1: Fake / Broken External URL
- **Bug**: The code attempted `requests.get("https://api.mock-twitter.com/v2/trends")`.
- **Failure**: This domain does not exist, throwing `requests.exceptions.ConnectionError: Failed to establish a new connection: [Errno 11001] getaddrinfo failed`.
- **Fix**: Replaced the non-existent HTTP endpoint with a robust local Mock Twitter API class (`MockTwitterAPI`) that returns realistic trending topics with hashtags, tweet counts, and viral sample tweets.

### Issue 2: Deprecated `LLMChain` & `from langchain.llms import OpenAI`
- **Bug**: In LangChain v0.3 / v1.0+, `from langchain.chains import LLMChain` and `chain.run()` are deprecated and trigger warnings or deprecation errors. Similarly, `from langchain.llms import OpenAI` has been migrated to `langchain_openai.ChatOpenAI`.
- **Fix**: Upgraded to the modern **LangChain Expression Language (LCEL)**:
  ```python
  # Modern LCEL pattern:
  chain = prompt | llm | StrOutputParser()
  summary = chain.invoke({"topic": topic, "tweets": tweets})
  ```

### Issue 3: Did Not Limit to Top 2 Trends
- **Bug**: The raw code looped over all trends (`for trend in trends:`) without slicing or sorting. The assignment explicitly required: *"print the top 2 trends in your console"*.
- **Fix**: Added sorting by `tweet_volume` descending and sliced the collection: `top_2_trends = sorted_trends[:2]`.

### Issue 4: Hardcoded Reliance on Paid OpenAI API Key
- **Bug**: `llm = OpenAI()` fails immediately with `openai.OpenAIError: The api_key client option must be set` if the user does not have an active paid OpenAI API key configured.
- **Fix**: Provided dynamic fallback: If `OPENAI_API_KEY` is present, it uses `ChatOpenAI(model="gpt-4o-mini")`; otherwise, it seamlessly uses LangChain's `FakeListChatModel` for deterministic, zero-cost, out-of-the-box execution.
